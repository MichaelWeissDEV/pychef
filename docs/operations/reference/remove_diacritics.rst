Remove Diacritics
=================

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Diacritic <https://wikipedia.org/wiki/Diacritic>`_

What it does
------------

Replaces accented characters with their latin character equivalent. Accented characters are made up
of Unicode combining characters, so unicode text formatting such as strikethroughs and underlines
will also be removed.

   Status here means the operation name is implemented and callable. It does not by
