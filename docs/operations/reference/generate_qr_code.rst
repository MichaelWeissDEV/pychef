Generate QR Code

What it does
------------

Generates a Quick Response (QR) code from the input text. A QR code is a type of matrix barcode (or
two-dimensional barcode) first designed in 1994 for the automotive industry in Japan. A barcode is a
machine-readable optical label that contains information about the item to which it is attached.
