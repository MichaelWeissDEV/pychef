Fuzzy Match
===========

**Category:** Analysis

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://wikipedia.org/wiki/Fuzzy_matching_(computer-assisted_translation) <https://wikipedia.org/wiki/Fuzzy_matching_(computer-assisted_translation)>`_

What it does
------------

Conducts a fuzzy search to find a pattern within the input based on weighted criteria. e.g. A search
for ``dpan`` will match on ``Don't Panic``

   Status here means the operation name is implemented and callable. It does not by
