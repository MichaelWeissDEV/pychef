Parse colour code
=================

**Category:** Data format

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://wikipedia.org/wiki/Web_colors <https://wikipedia.org/wiki/Web_colors>`_

What it does
------------

Converts a colour code in a standard format to other standard formats and displays the colour
itself. Example inputs

- ``#d9edf7``

- ``rgba(217,237,247,1)``

- ``hsla(200,65%,91%,1)``

- ``cmyk(0.12, 0.04, 0.00, 0.03)``
