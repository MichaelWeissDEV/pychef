What it does
------------

MD5 (Message-Digest 5) is a widely used hash function. It has been used in a variety of security
applications and is also commonly used to check the integrity of files. However, MD5 is not
collision resistant and it isn't suitable for applications like SSL/TLS certificates or digital
signatures that rely on this property.
