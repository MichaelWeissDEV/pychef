What it does
------------

Ascon-Mac produces a 128-bit (16-byte) message authentication code as part of the Ascon family
standardised by NIST in SP 800-232. It provides authentication for messages using a secret key,
ensuring both data integrity and authenticity. Ascon is designed for lightweight cryptography on
constrained devices such as IoT sensors and embedded systems.
