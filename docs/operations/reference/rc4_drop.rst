RC4 Drop
========

**Category:** Ciphers

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/RC4#Fluhrer,_Mantin_and_Shamir_attack <https://wikipedia.org/wiki/RC4#Fluhrer,_Mantin_and_Shamir_attack>`_

What it does
------------

It was discovered that the first few bytes of the RC4 keystream are strongly non-random and leak
information about the key. We can defend against this attack by discarding the initial portion of
the keystream. This modified algorithm is traditionally called RC4-drop.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
