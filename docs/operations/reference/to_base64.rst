To Base64
=========

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``string``

**Background:** `https://wikipedia.org/wiki/Base64 <https://wikipedia.org/wiki/Base64>`_

What it does
------------

Base64 is a notation for encoding arbitrary byte data using a restricted set of symbols that can be
conveniently used by humans and processed by computers. This operation encodes raw data into an
ASCII Base64 string. e.g. ``hello`` becomes ``aGVsbG8=``

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
