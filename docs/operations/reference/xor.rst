XOR
========

**Category:** Bitwise

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``byteArray``

**Background:** `https://wikipedia.org/wiki/XOR <https://wikipedia.org/wiki/XOR>`_

What it does
------------

XOR the input with the given key. e.g. ``fe023da5`` Options Null preserving: If the current byte is
0x00 or the same as the key, skip it. Scheme:

- Standard - key is unchanged after each round

- Input differential - key is set to the value of the previous unprocessed byte

- Output differential - key is set to the value of the previous processed byte

- Cascade - key is set to the input byte shifted by one

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
