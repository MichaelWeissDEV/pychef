Extract Audio Metadata
======================

**Category:** Forensics

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``JSON``

**Background:** `https://wikipedia.org/wiki/Audio_file_format <https://wikipedia.org/wiki/Audio_file_format>`_

What it does
------------

Extract common audio metadata across MP3 (ID3v2/ID3v1/GEOB), WAV/BWF/BW64 (INFO/bext/iXML/axml),
FLAC (Vorbis Comment/Picture), OGG (Vorbis/OpusTags), AAC (ADTS), AC3 (Dolby Digital), WMA (ASF),
plus best-effort MP4/M4A and AIFF scanning. Outputs normalized JSON.
