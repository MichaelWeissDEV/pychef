Strip HTTP headers
==================

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Hypertext_Transfer_Protocol#Message_format <https://wikipedia.org/wiki/Hypertext_Transfer_Protocol#Message_format>`_

What it does
------------

Removes HTTP headers from a request or response by looking for the first instance of a double
newline.

   Status here means the operation name is implemented and callable. It does not by
