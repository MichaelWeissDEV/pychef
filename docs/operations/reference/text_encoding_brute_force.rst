Text Encoding Brute Force
=========================

**Category:** Encodings

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``json``

**Background:** `https://wikipedia.org/wiki/Character_encoding <https://wikipedia.org/wiki/Character_encoding>`_

What it does
------------

Enumerates all supported text encodings for the input, allowing you to quickly spot the correct one.
Supported charsets are:

- ${e}
