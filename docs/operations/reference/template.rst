Template
========

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``JSON`` → ``string``

**Background:** `https://handlebarsjs.com/ <https://handlebarsjs.com/>`_

What it does
------------

Render a template with Handlebars/Mustache substituting variables using JSON input. Templates will
be rendered to plain-text only, to prevent XSS.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.

.. warning::

   The pure-Python renderer supports variables, raw variables, each/if/unless blocks, parent and root paths, and inline partials; arbitrary Handlebars helpers are not available.
