Extract LSB
===========

**Category:** Image

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``byteArray``

**Background:** `https://wikipedia.org/wiki/Bit_numbering#Least_significant_bit_in_digital_steganography <https://wikipedia.org/wiki/Bit_numbering#Least_significant_bit_in_digital_steganography>`_

What it does
------------

Extracts the Least Significant Bit data from each pixel in an image. This is a common way to hide
data in Steganography.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
