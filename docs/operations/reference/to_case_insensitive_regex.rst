To Case Insensitive Regex
=========================

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Regular_expression <https://wikipedia.org/wiki/Regular_expression>`_

What it does
------------

Converts a case-sensitive regex string into a case-insensitive regex string in case the i flag is
unavailable to you. e.g. ``Mozilla/[0-9].[0-9] .*`` becomes
``[mM][oO][zZ][iI][lL][lL][aA]/[0-9].[0-9] .*``
