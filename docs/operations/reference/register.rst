Register
========

**Category:** Flow control

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Regular_expression#Syntax <https://wikipedia.org/wiki/Regular_expression#Syntax>`_

What it does
------------

Extract data from the input and store it in registers which can then be passed into subsequent
operations as arguments. Regular expression capture groups are used to select the data to extract.
To use registers in arguments, refer to them using the notation ``$Rn`` where n is the register
number, starting at 0. For example: Input: ``Test`` Extractor: ``(.*)`` Argument: ``$R0`` becomes
``Test`` Registers can be escaped in arguments using a backslash. e.g. ``\$R0`` would become ``$R0``
rather than ``Test``.
