From UNIX Timestamp
===================

**Category:** Date / Time

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``number`` → ``string``

**Background:** `https://wikipedia.org/wiki/Unix_time <https://wikipedia.org/wiki/Unix_time>`_

What it does
------------

Converts a UNIX timestamp to a datetime string. e.g. ``978346800`` becomes ``Mon 1 January 2001
11:00:00 UTC`` A UNIX timestamp is a 32-bit value representing the number of seconds since January
1, 1970 UTC (the UNIX epoch).

   Status here means the operation name is implemented and callable. It does not by
