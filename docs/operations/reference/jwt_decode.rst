JWT Decode
==========

**Category:** Serialisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``JSON``

**Background:** `https://wikipedia.org/wiki/JSON_Web_Token <https://wikipedia.org/wiki/JSON_Web_Token>`_

What it does
------------

Decodes a JSON Web Token without checking whether the provided secret / private key is valid. Use
'JWT Verify' to check if the signature is valid as well.
