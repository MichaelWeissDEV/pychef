Hex to PEM
==========

**Category:** Public Key

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Privacy-Enhanced_Mail <https://wikipedia.org/wiki/Privacy-Enhanced_Mail>`_

What it does
------------

Converts a hexadecimal DER (Distinguished Encoding Rules) string into PEM (Privacy Enhanced Mail)
format.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
