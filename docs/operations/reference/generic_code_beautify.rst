Generic Code Beautify
=====================

**Category:** Code

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

What it does
------------

Attempts to pretty print C-style languages such as C, C++, C#, Java, PHP, JavaScript etc. This will
not do a perfect job, and the resulting code may not work any more. This operation is designed
purely to make obfuscated or minified code more easy to read and understand. Things which will not
work properly:

- For loop formatting

- Do-While loop formatting

- Switch/Case indentation

- Certain bit shift operators
