Parse Ethernet frame
====================

**Category:** Networking

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://en.wikipedia.org/wiki/Ethernet_frame#Frame_%E2%80%93_data_link_layer <https://en.wikipedia.org/wiki/Ethernet_frame#Frame_%E2%80%93_data_link_layer>`_

What it does
------------

Parses an Ethernet frame and either shows the deduced values (Source and destination MAC, VLANs) or
returns the packet data. Good for use in conjunction with the Parse IPv4, and Parse TCP/UDP recipes.

.. note::
