Pseudo-Random Prime Generator
=============================

**Category:** Generators

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Miller-Rabin_primality_test <https://wikipedia.org/wiki/Miller-Rabin_primality_test>`_

What it does
------------

Generates a random probable prime number of specified bit length using the Miller-Rabin primality
test. Primality guarantee: For numbers . 3,317, the result is guaranteed prime (deterministic test).
For larger numbers, uses probabilistic testing:

- Standard (7 rounds): Probability of composite approx 1 in 16,000)

- Crypto grade (40 rounds): Probability of composite(approx 1 in 10^24)

Crypto grade is recommended for cryptographic applications (RSA, Diffie-Hellman, etc.).
