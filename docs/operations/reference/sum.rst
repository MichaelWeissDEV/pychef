Sum
========

**Category:** Arithmetic

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``BigNumber``

**Background:** `https://wikipedia.org/wiki/Summation <https://wikipedia.org/wiki/Summation>`_

What it does
------------

Adds together a list of numbers. If an item in the string is not a number it is excluded from the
list. e.g. ``0x0a 8 .5`` becomes ``18.5``
