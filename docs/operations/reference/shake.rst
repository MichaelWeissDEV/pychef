Shake
========

**Category:** Hashing

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``string``

**Background:** `https://wikipedia.org/wiki/SHA-3#Instances <https://wikipedia.org/wiki/SHA-3#Instances>`_

What it does
------------

Shake is an Extendable Output Function (XOF) of the SHA-3 hash algorithm, part of the Keccak family,
allowing for variable output length/size.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
