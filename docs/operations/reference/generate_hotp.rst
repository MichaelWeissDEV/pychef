What it does
------------

The HMAC-based One-Time Password algorithm (HOTP) is an algorithm that computes a one-time password
from a shared secret key and an incrementing counter. It has been adopted as Internet Engineering
Task Force standard RFC 4226, is the cornerstone of Initiative For Open Authentication (OAUTH), and
is used in a number of two-factor authentication systems. Enter the secret as the input or leave it
blank for a random secret to be generated. The secret must be a valid base32 string (characters A–Z
and 2–7).
