File Tree
=========

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Background:** `https://wikipedia.org/wiki/Tree_(command) <https://wikipedia.org/wiki/Tree_(command)>`_

What it does
------------

Creates a file tree from a list of file paths (similar to the tree command in Linux)
