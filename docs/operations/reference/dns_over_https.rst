DNS over HTTPS
==============

**Category:** Networking

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``JSON``

What it does
------------

Takes a single domain name and performs a DNS lookup using DNS over HTTPS. By default, Cloudflare
and Google DNS over HTTPS services are supported. Can be used with any service that supports the GET
parameters ``name`` and ``type``.

   Status here means the operation name is implemented and callable. It does not by
