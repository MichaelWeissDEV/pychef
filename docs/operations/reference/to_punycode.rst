To Punycode
===========

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Background:** `https://wikipedia.org/wiki/Punycode <https://wikipedia.org/wiki/Punycode>`_

What it does
------------

Punycode is a way to represent Unicode with the limited character subset of ASCII supported by the
Domain Name System. e.g. ``m\xfcnchen`` encodes to ``mnchen-3ya``
