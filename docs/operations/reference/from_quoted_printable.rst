From Quoted Printable
=====================

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``byteArray``

**Background:** `https://wikipedia.org/wiki/Quoted-printable <https://wikipedia.org/wiki/Quoted-printable>`_

What it does
------------

Converts QP-encoded text back to standard text. This format is a content transfer encoding common in
email messages. e.g. The quoted-printable encoded string ``hello=20world`` becomes ``hello world``
