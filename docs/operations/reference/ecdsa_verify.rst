ECDSA Verify
============

**Category:** Public Key

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Elliptic_Curve_Digital_Signature_Algorithm <https://wikipedia.org/wiki/Elliptic_Curve_Digital_Signature_Algorithm>`_

What it does
------------

Verify a message against a signature and a public PEM encoded EC key.
