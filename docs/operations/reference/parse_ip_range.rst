Parse IP range
==============

**Category:** Networking

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Subnetwork <https://wikipedia.org/wiki/Subnetwork>`_

What it does
------------

Given a CIDR range (e.g. ``10.0.0.0/24``), hyphenated range (e.g. ``10.0.0.0 - 10.0.1.0``), or a
list of IPs and/or CIDR ranges (separated by a new line), this operation provides network
information and enumerates all IP addresses in the range. IPv6 is supported but will not be
enumerated.
