Get Time
========

**Category:** Date / Time

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``number``

**Background:** `https://wikipedia.org/wiki/Unix_time <https://wikipedia.org/wiki/Unix_time>`_

What it does
------------

Generates a timestamp showing the amount of time since the UNIX epoch (1970-01-01 00:00:00 UTC).
Uses the W3C High Resolution Time API.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
