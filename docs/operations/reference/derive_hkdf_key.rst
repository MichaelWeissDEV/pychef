Derive HKDF key
===============

**Category:** KDF

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``string``

**Background:** `https://wikipedia.org/wiki/HKDF <https://wikipedia.org/wiki/HKDF>`_

What it does
------------

A simple Hashed Message Authenticaton Code (HMAC)-based key derivation function (HKDF), defined in
RFC5869.

.. note::

   Status here means the operation name is implemented and callable. It does not by
