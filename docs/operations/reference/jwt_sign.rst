JWT Sign
========

**Category:** Authentication

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``JSON`` → ``string``

**Background:** `https://wikipedia.org/wiki/JSON_Web_Token <https://wikipedia.org/wiki/JSON_Web_Token>`_

What it does
------------

Signs a JSON object as a JSON Web Token using a provided secret / private key. The key should be
either the secret for HMAC algorithms or the PEM-encoded private key for RSA and ECDSA.
