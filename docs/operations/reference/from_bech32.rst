What it does
------------

Bech32 is an encoding scheme primarily used for Bitcoin SegWit addresses (BIP-0173). It uses a
32-character alphabet that excludes easily confused characters (1, b, i, o) and includes a checksum
for error detection. Bech32m (BIP-0350) is an updated version used for Bitcoin Taproot addresses.
Auto-detect will attempt Bech32 first, then Bech32m if the checksum fails. Output format options
allow you to see the Human-Readable Part (HRP) along with the decoded data.
