Extract EXIF
============

**Background:** `https://wikipedia.org/wiki/Exif <https://wikipedia.org/wiki/Exif>`_

What it does
------------

Extracts EXIF data from an image. EXIF data is metadata embedded in images (JPEG, JPG, TIFF) and
audio files. EXIF data from photos usually contains information about the image file itself as well
as the device used to create it.
