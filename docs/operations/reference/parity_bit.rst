What it does
------------

A parity bit, or check bit, is the simplest form of error detection. It is a bit which is added to a
string of bits and represents if the number of 1's in the binary string is an even number or odd
number. If a delimiter is specified, the parity bit calculation will be performed on each 'block' of
the input data, where the blocks are created by slicing the input at each occurrence of the
delimiter character

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
