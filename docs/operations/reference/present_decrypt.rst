What it does
------------

PRESENT is an ultra-lightweight block cipher designed for constrained environments such as RFID tags
and sensor networks. It operates on 64-bit blocks and supports 80-bit or 128-bit keys with 31
rounds. Standardised in ISO/IEC 29192-2:2019. When using CBC mode, the PKCS#7 padding scheme is
used.
