Add Text To Image
=================

**Category:** Image

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``ArrayBuffer``

What it does
------------

Adds text onto an image. Text can be horizontally or vertically aligned, or the position can be
manually specified. Variants of the Roboto font face are available in any size or colour.

   Status here means the operation name is implemented and callable. It does not by
