What it does
------------

BSON is a computer data interchange format used mainly as a data storage and network transfer format
in the MongoDB database. It is a binary form for representing simple data structures, associative
arrays (called objects or documents in MongoDB), and various data types of specific interest to
MongoDB. The name 'BSON' is based on the term JSON and stands for 'Binary JSON'. Input data should
be valid JSON.
