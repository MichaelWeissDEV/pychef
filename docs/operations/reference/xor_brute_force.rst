XOR Brute Force
===============

**Category:** Ciphers

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``string``

**Background:** `https://wikipedia.org/wiki/Exclusive_or <https://wikipedia.org/wiki/Exclusive_or>`_

What it does
------------

Enumerate all possible XOR solutions. Current maximum key length is 2 due to browser performance.
Optionally enter a string that you expect to find in the plaintext to filter results (crib).

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
