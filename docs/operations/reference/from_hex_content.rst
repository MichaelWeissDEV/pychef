What it does
------------

Translates hexadecimal bytes in text back to raw bytes. This format is used by SNORT for
representing hex within ASCII text. e.g. ``foo|3d|bar`` becomes ``foo=bar``.

.. note::

   Status here means the operation name is implemented and callable. It does not by
