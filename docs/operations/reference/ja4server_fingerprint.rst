JA4Server Fingerprint
=====================

**Category:** Crypto

What it does
------------

Generates a JA4Server Fingerprint (JA4S) to help identify TLS servers or sessions based on hashing
together values from the Server Hello. Input: A hex stream of the TLS or QUIC Server Hello packet
application layer.

.. note::

   Status here means the operation name is implemented and callable. It does not by
