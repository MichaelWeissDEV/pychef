Escape Unicode Characters
=========================

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

What it does
------------

Converts characters to their unicode-escaped notations. Supports the prefixes:

- ``\u``

- ``%u``

- ``U+``

e.g. ``σου`` becomes ``\u03C3\u03BF\u03C5``
