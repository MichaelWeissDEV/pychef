What it does
------------

Twofish is a symmetric key block cipher designed by Bruce Schneier. It was one of the five AES
finalists. Twofish operates on 128-bit blocks and supports key sizes of 128, 192, or 256 bits with
16 rounds of a Feistel network. When using CBC or ECB mode, the PKCS#7 padding scheme is used.
