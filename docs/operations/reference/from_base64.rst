From Base64
===========

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``byteArray``

**Background:** `https://wikipedia.org/wiki/Base64 <https://wikipedia.org/wiki/Base64>`_

What it does
------------

Base64 is a notation for encoding arbitrary byte data using a restricted set of symbols that can be
conveniently used by humans and processed by computers. This operation decodes data from an ASCII
Base64 string back into its raw format. e.g. ``aGVsbG8=`` becomes ``hello``
