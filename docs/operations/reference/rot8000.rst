ROT8000
========

**Category:** Ciphers

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Background:** `https://rot8000.com/info <https://rot8000.com/info>`_

What it does
------------

The simple Caesar-cypher encryption that replaces each Unicode character with the one 0x8000 places
forward or back along the alphabet.

.. note::

   Status here means the operation name is implemented and callable. It does not by
