Derive EVP key

What it does
------------

This operation performs a password-based key derivation function (PBKDF) used extensively in
OpenSSL. In many applications of cryptography, user security is ultimately dependent on a password,
and because a password usually can't be used directly as a cryptographic key, some processing is
required. A salt provides a large set of keys for any given password, and an iteration count
increases the cost of producing keys from a password, thereby also increasing the difficulty of
attack. If you leave the salt argument empty, a random salt will be generated.
