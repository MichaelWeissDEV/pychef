BLAKE2b
========

**Category:** Hashing

**Background:** `https://wikipedia.org/wiki/BLAKE_(hash_function)#BLAKE2b_algorithm <https://wikipedia.org/wiki/BLAKE_(hash_function)#BLAKE2b_algorithm>`_

What it does
------------

Performs BLAKE2b hashing on the input. BLAKE2b is a flavour of the BLAKE cryptographic hash function
that is optimized for 64-bit platforms and produces digests of any size between 1 and 64 bytes.
Supports the use of an optional key.
