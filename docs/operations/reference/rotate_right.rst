Rotate right
============

**Category:** Bitwise

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``byteArray`` → ``byteArray``

**Background:** `https://wikipedia.org/wiki/Bitwise_operation#Bit_shifts <https://wikipedia.org/wiki/Bitwise_operation#Bit_shifts>`_

What it does
------------

Rotates each byte to the right by the number of bits specified, optionally carrying the excess bits
over to the next byte. Currently only supports 8-bit values.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
