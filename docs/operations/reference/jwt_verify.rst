JWT Verify
==========

**Category:** Authentication

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``JSON``

**Background:** `https://wikipedia.org/wiki/JSON_Web_Token <https://wikipedia.org/wiki/JSON_Web_Token>`_

What it does
------------

Verifies that a JSON Web Token is valid and has been signed with the provided secret / private key.
The key should be either the secret for HMAC algorithms or the PEM-encoded public key for RSA and
ECDSA.
