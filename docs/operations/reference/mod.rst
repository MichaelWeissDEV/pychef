MOD
========

**Category:** Arithmetic

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

What it does
------------

Computes the modulo of each number in a list with a given modulus value. Numbers are extracted from
the input based on the delimiter, and non-numeric values are ignored. e.g. ``15 4 7`` with modulus
``3`` becomes ``0 1 1``
