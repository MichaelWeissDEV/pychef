Parse UNIX file permissions
===========================

What it does
------------

Given a UNIX/Linux file permission string in octal or textual format, this operation explains which
permissions are granted to which user groups. Input should be in either octal (e.g. ``755``) or
textual (e.g. ``drwxr-xr-x``) format.
