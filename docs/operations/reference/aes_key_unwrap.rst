AES Key Unwrap
==============

What it does
------------

Decryptor for a key wrapping algorithm defined in RFC3394, which is used to protect keys in
untrusted storage or communications, using AES. This algorithm uses an AES key (KEK: key-encryption
key) and a 64-bit IV to decrypt 64-bit blocks.
