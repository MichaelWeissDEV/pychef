Scan for Embedded Files
=======================

**Category:** Forensics

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``string``

**Background:** `https://wikipedia.org/wiki/List_of_file_signatures <https://wikipedia.org/wiki/List_of_file_signatures>`_

What it does
------------

Scans the data for potential embedded files by looking for magic bytes at all offsets. This
operation is prone to false positives. WARNING: Files over about 100KB in size will take a VERY long
time to process.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See

   scope and known boundaries.
