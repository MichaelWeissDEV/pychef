Parse DateTime
==============

**Category:** Date / Time

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://momentjs.com/docs/#/parsing/string-format/ <https://momentjs.com/docs/#/parsing/string-format/>`_

What it does
------------

Parses a DateTime string in your specified format and displays it in whichever timezone you choose
with the following information:

- Date

- Time

- Period (AM/PM)

- Timezone

- UTC offset

- Daylight Saving Time

- Leap year

- Days in this month

- Day of year

- Week number

- Quarter

Run with no input to see format string examples if required.
