Head
========

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

What it does
------------

Like the UNIX head utility. Gets the first n lines. You can select all but the last n lines by
entering a negative value for n. The delimiter can be changed so that instead of lines, fields (i.e.
commas) are selected instead.
