Format MAC addresses
====================

**Category:** Networking

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/MAC_address#Notational_conventions <https://wikipedia.org/wiki/MAC_address#Notational_conventions>`_

What it does
------------

Displays given MAC addresses in multiple different formats. Expects addresses in a list separated by
newlines, spaces or commas. WARNING: There are no validity checks.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
