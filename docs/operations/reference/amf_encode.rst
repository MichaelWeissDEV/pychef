AMF Encode
==========

**Category:** Encodings

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``JSON`` → ``ArrayBuffer``

**Background:** `https://wikipedia.org/wiki/Action_Message_Format <https://wikipedia.org/wiki/Action_Message_Format>`_

What it does
------------

Action Message Format (AMF) is a binary format used to serialize object graphs such as ActionScript
objects and XML, or send messages between an Adobe Flash client and a remote service, usually a
Flash Media Server or third party alternatives.

.. note::

   Status here means the operation name is implemented and callable. It does not by

   :doc:`../../compatibility` for the verified
   scope and known boundaries.

.. warning::

   AMF3 externalizable values are not fully interoperable.
