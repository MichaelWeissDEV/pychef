Modular Inverse
===============

**Category:** Arithmetic

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Modular_multiplicative_inverse <https://wikipedia.org/wiki/Modular_multiplicative_inverse>`_

What it does
------------

Computes the modular multiplicative inverse of a modulo m. Finds x such that a*x = 1 (mod m). Input
handling: If either a or m is left blank, its value is taken from the Input field.
