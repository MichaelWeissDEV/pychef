URL Decode
==========

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Percent-encoding <https://wikipedia.org/wiki/Percent-encoding>`_

What it does
------------

Converts URI/URL percent-encoded characters back to their raw values. e.g. ``%3d`` becomes ``=``

.. note::

   Status here means the operation name is implemented and callable. It does not by
