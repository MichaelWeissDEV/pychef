Parse TLV
=========

**Category:** Serialisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``JSON``

**Background:** `https://wikipedia.org/wiki/Type-length-value <https://wikipedia.org/wiki/Type-length-value>`_

What it does
------------

Converts a Type-Length-Value (TLV) encoded string into a JSON object. Can optionally include a
``Key`` / ``Type`` entry. Tags: Key-Length-Value, KLV, Length-Value, LV

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
