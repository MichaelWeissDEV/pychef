To HTML Entity
==============

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/List_of_XML_and_HTML_character_entity_references <https://wikipedia.org/wiki/List_of_XML_and_HTML_character_entity_references>`_

What it does
------------

Converts characters to HTML entities e.g. ``&`` becomes ``&amp;``

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
