What it does
------------

X.509 is an ITU-T standard for a public key infrastructure (PKI) and Privilege Management
Infrastructure (PMI). It is commonly involved with SSL/TLS security. This operation displays the
contents of a certificate in a human readable format, similar to the openssl command line tool.
Tags: X509, server hello, handshake
