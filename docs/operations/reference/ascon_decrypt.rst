What it does
------------

Ascon-AEAD128 authenticated decryption as standardised in NIST SP 800-232. Decrypts ciphertext and
verifies the authentication tag. Decryption will fail if the ciphertext or associated data has been
tampered with. Key: Must be exactly 16 bytes (128 bits). Nonce: Must be exactly 16 bytes (128 bits).
Must match the nonce used during encryption. Associated Data: Must match the associated data used
during encryption. Any mismatch will cause authentication failure.
