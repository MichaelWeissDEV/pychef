Protobuf Encode
===============

**Category:** Serialise

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``JSON`` → ``ArrayBuffer``

**Background:** `https://developers.google.com/protocol-buffers/docs/encoding <https://developers.google.com/protocol-buffers/docs/encoding>`_

What it does
------------

Encodes a valid JSON object into a protobuf byte array using the input .proto schema.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
