Unzip
========

**Category:** Compression

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``List<File>``

**Background:** `https://wikipedia.org/wiki/Zip_(file_format) <https://wikipedia.org/wiki/Zip_(file_format)>`_

What it does
------------

Decompresses data using the PKZIP algorithm and displays it per file, with support for passwords.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See

   scope and known boundaries.
