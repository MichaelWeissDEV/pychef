Disassemble x86
===============

**Category:** Shellcode

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/X86 <https://wikipedia.org/wiki/X86>`_

What it does
------------

Disassembly is the process of translating machine language into assembly language. This operation
supports 64-bit, 32-bit and 16-bit code written for Intel or AMD x86 processors. It is particularly
useful for reverse engineering shellcode. Input should be in hexadecimal.
