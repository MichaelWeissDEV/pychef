What it does
------------

Blowfish is a symmetric-key block cipher designed in 1993 by Bruce Schneier and included in a large
number of cipher suites and encryption products. AES now receives more attention. IV: The
Initialization Vector should be 8 bytes long. If not entered, it will default to 8 null bytes.
