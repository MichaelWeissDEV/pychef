What it does
------------

Triple DES applies DES three times to each block to increase key size. Key: Triple DES uses a key
length of 24 bytes (192 bits). You can generate a password-based key using one of the KDF
operations. IV: The Initialization Vector should be 8 bytes long. If not entered, it will default to
8 null bytes. Padding: In CBC and ECB mode, PKCS#7 padding will be used.
