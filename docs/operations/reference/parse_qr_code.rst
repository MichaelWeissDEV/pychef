Parse QR Code
=============

**Category:** Image

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``string``

**Background:** `https://wikipedia.org/wiki/QR_code <https://wikipedia.org/wiki/QR_code>`_

What it does
------------

Reads an image file and attempts to detect and read a Quick Response (QR) code from the image.
Normalise Image Attempts to normalise the image before parsing it to improve detection of a QR code.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.

.. warning::

   General QR-symbol decoding is not yet at full upstream parity.
