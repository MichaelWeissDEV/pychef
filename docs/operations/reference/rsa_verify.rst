RSA Verify
==========

**Category:** Public Key

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/RSA_(cryptosystem) <https://wikipedia.org/wiki/RSA_(cryptosystem)>`_

What it does
------------

Verify a message against a signature and a public PEM encoded RSA key.
