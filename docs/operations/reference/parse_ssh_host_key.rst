Parse SSH Host Key
==================

**Category:** Public Key

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Secure_Shell <https://wikipedia.org/wiki/Secure_Shell>`_

What it does
------------

Parses a SSH host key and extracts fields from it. The key type can be:

- ssh-rsa

- ssh-dss

- ecdsa-sha2

- ssh-ed25519

The key format can be either Hex or Base64.
