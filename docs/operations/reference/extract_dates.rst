Extract dates
=============

**Category:** Extraction

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

What it does
------------

Extracts dates in the following formats

- ``yyyy-mm-dd``

- ``dd/mm/yyyy``

- ``mm/dd/yyyy``

Dividers can be any of /, -, . or space
