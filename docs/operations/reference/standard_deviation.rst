Standard Deviation
==================

**Category:** Arithmetic

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``BigNumber``

**Background:** `https://wikipedia.org/wiki/Standard_deviation <https://wikipedia.org/wiki/Standard_deviation>`_

What it does
------------

Computes the standard deviation of a number list. If an item in the string is not a number it is
excluded from the list. e.g. ``0x0a 8 .5`` becomes ``4.089281382128433``

.. note::

   Status here means the operation name is implemented and callable. It does not by
