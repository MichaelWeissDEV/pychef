Generate UUID
=============

What it does
------------

Generates an RFC 9562 (formerly RFC 4122) compliant Universally Unique Identifier (UUID), also known
as a Globally Unique Identifier (GUID). We currently support generating the following UUID versions:

- v1: Timestamp-based

- v3: Namespace w/ MD5

- v4: Random (default)

- v5: Namespace w/ SHA-1

- v6: Timestamp, reordered

- v7: Unix Epoch time-based

UUIDs are generated using the ``uuid`` package.
