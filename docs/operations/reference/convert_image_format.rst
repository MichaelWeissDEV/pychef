Convert Image Format
====================

**Category:** Image

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``ArrayBuffer``

**Background:** `https://wikipedia.org/wiki/Image_file_formats <https://wikipedia.org/wiki/Image_file_formats>`_

What it does
------------

Converts an image between different formats. Supported formats:

- Joint Photographic Experts Group (JPEG)

- Portable Network Graphics (PNG)

- Bitmap (BMP)

- Tagged Image File Format (TIFF)

Note: GIF files are supported for input, but cannot be outputted.
