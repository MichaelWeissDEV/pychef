What it does
------------

Abstract Syntax Notation One (ASN.1) is a standard and notation that describes rules and structures
for representing, encoding, transmitting, and decoding data in telecommunications and computer
networking. This operation parses arbitrary ASN.1 data (encoded as an hex string: use the 'To Hex'
operation if necessary) and presents the resulting tree.
