What it does
------------

Snefru is a cryptographic hash function invented by Ralph Merkle in 1990 while working at Xerox
PARC. The function supports 128-bit and 256-bit output. It was named after the Egyptian Pharaoh
Sneferu, continuing the tradition of the Khufu and Khafre block ciphers. The original design of
Snefru was shown to be insecure by Eli Biham and Adi Shamir who were able to use differential
cryptanalysis to find hash collisions. The design was then modified by increasing the number of
iterations of the main pass of the algorithm from two to eight.
