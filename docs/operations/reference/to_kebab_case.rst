To Kebab case
=============

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Kebab_case <https://wikipedia.org/wiki/Kebab_case>`_

What it does
------------

Converts the input string to kebab case. Kebab case is all lower case with dashes as word
boundaries. e.g. this-is-kebab-case 'Attempt to be context aware' will make the operation attempt to
nicely transform variable and function names.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
