Heatmap chart
=============

**Category:** Visualisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://wikipedia.org/wiki/Heat_map <https://wikipedia.org/wiki/Heat_map>`_

What it does
------------

A heatmap is a graphical representation of data where the individual values contained in a matrix
are represented as colors.
