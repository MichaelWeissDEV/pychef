Translate DateTime Format
=========================

**Category:** Date / Time

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://momentjs.com/docs/#/parsing/string-format/ <https://momentjs.com/docs/#/parsing/string-format/>`_

What it does
------------

Parses a datetime string in one format and re-writes it in another. Run with no input to see the
relevant format string examples.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See

   scope and known boundaries.
