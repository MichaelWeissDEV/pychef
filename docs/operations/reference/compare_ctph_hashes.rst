Compare CTPH hashes
===================

**Category:** Hashing

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``Number``

**Background:** `https://forensics.wiki/context_triggered_piecewise_hashing/ <https://forensics.wiki/context_triggered_piecewise_hashing/>`_

What it does
------------

Compares two Context Triggered Piecewise Hashing (CTPH) fuzzy hashes to determine the similarity
between them on a scale of 0 to 100.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
