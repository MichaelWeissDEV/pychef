Disassemble ARM
===============

**Category:** Shellcode

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/ARM_architecture_family <https://wikipedia.org/wiki/ARM_architecture_family>`_

What it does
------------

Disassembles ARM machine code into assembly language. Supports ARM (32-bit), Thumb, and ARM64
(AArch64) architectures using the Capstone disassembly framework. Input should be in hexadecimal.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
