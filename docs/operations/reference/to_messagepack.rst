To MessagePack
==============

**Category:** Serialisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``JSON`` → ``ArrayBuffer``

**Background:** `https://wikipedia.org/wiki/MessagePack <https://wikipedia.org/wiki/MessagePack>`_

What it does
------------

Converts JSON to MessagePack encoded byte buffer. MessagePack is a computer data interchange format.
It is a binary form for representing simple data structures like arrays and associative arrays.
