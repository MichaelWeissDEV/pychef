PGP Verify
==========

**Category:** PGP

**Background:** `https://wikipedia.org/wiki/Pretty_Good_Privacy <https://wikipedia.org/wiki/Pretty_Good_Privacy>`_

What it does
------------

Input: the ASCII-armoured encrypted PGP message you want to verify. Argument: the ASCII-armoured PGP
public key of the signer This operation uses PGP to decrypt a clearsigned message. Pretty Good
Privacy is an encryption standard (OpenPGP) used for encrypting, decrypting, and signing messages.
This function uses the Keybase implementation of PGP.
