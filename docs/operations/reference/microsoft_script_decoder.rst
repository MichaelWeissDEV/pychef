Microsoft Script Decoder
========================

**Category:** Default

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/JScript.Encode <https://wikipedia.org/wiki/JScript.Encode>`_

What it does
------------

Decodes Microsoft Encoded Script files that have been encoded with Microsoft's custom encoding.
These are often VBS (Visual Basic Script) files that are encoded and renamed with a '.vbe' extention
or JS (JScript) files renamed with a '.jse' extention. Sample Encoded:
``#@~^RQAAAA==-mD~sX|:/TP{~J:+dYbxL~@!F@*@!+@*@!&@*eEI@#@&@#@&.jm.raY 214Wv:zms/obI0xEAAA==^#~@``
Decoded: ``var my_msg = "Testing !"; VScript.Echo(my_msg);``
