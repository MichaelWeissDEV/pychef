Defang IP Addresses
===================

**Category:** Networking

What it does
------------

Takes a IPv4 or IPv6 address and 'Defangs' it, meaning the IP becomes invalid, removing the risk of
accidentally utilising it as an IP address.

.. note::

   Status here means the operation name is implemented and callable. It does not by
