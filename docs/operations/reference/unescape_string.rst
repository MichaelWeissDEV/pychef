Unescape string
===============

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Escape_sequence <https://wikipedia.org/wiki/Escape_sequence>`_

What it does
------------

Unescapes characters in a string that have been escaped. For example, ``Don\'t stop me now`` becomes
``Don't stop me now``. Supports the following escape sequences:

- ``\n`` (Line feed/newline)

- ``\r`` (Carriage return)

- ``\t`` (Horizontal tab)

- ``\b`` (Backspace)

- ``\f`` (Form feed)

- ``\nnn`` (Octal, where n is 0-7)

- ``\xnn`` (Hex, where n is 0-f)

- ``\\`` (Backslash)

- ``\'`` (Single quote)

- ``\"`` (Double quote)

- ``\unnnn`` (Unicode character)

- ``\u{nnnnnn}`` (Unicode code point)
