Modular Exponentiation
======================

**Category:** Arithmetic

What it does
------------

Performs modular exponentiation, as used in Diffie-Hellman and RSA. Computes Base ^ Exponent mod
Modulus. Input handling: If either Base or Exponent is left blank, its value is taken from the Input
field.
