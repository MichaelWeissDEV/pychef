What it does
------------

Base58 (similar to Base64) is a notation for encoding arbitrary byte data. It differs from Base64 by
removing easily misread characters (i.e. l, I, 0 and O) to improve human readability. This operation
encodes data in an ASCII string (with an alphabet of your choosing, presets included). e.g. ``hello
world`` becomes ``StV1DL6CwTryKyV`` Base58 is commonly used in cryptocurrencies (Bitcoin, Ripple,
etc).
