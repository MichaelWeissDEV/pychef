Crop Image
==========

**Category:** Image

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``ArrayBuffer``

**Background:** `https://wikipedia.org/wiki/Cropping_(image) <https://wikipedia.org/wiki/Cropping_(image)>`_

What it does
------------

Crops an image to the specified region, or automatically crops edges. Autocrop Automatically crops
same-colour borders from the image. Autocrop tolerance A percentage value for the tolerance of
colour difference between pixels. Only autocrop frames Only crop real frames (all sides must have
the same border) Symmetric autocrop Force autocrop to be symmetric (top/bottom and left/right are
cropped by the same amount) Autocrop keep border The number of pixels of border to leave around the
image.
