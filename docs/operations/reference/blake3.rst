BLAKE3
========

**Category:** Hashing

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://en.wikipedia.org/wiki/BLAKE_(hash_function)#BLAKE3 <https://en.wikipedia.org/wiki/BLAKE_(hash_function)#BLAKE3>`_

What it does
------------

Hashes the input using BLAKE3 (UTF-8 encoded), with an optional key (also UTF-8), and outputs the
result in hexadecimal format.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See

   scope and known boundaries.
