Extended GCD
============

**Category:** Arithmetic

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Extended_Euclidean_algorithm <https://wikipedia.org/wiki/Extended_Euclidean_algorithm>`_

What it does
------------

Computes the Extended Euclidean Algorithm for integers a and b. Finds integers x and y (Bezout
coefficients) such that: a*x + b*y = gcd(a, b) This is fundamental to many number theory algorithms
including modular inverse, solving linear Diophantine equations, and cryptographic operations. Input
handling: If either a or b is left blank, its value is taken from the Input field.
