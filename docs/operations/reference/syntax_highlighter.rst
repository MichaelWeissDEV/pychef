Syntax highlighter
==================

**Category:** Rendering

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://wikipedia.org/wiki/Syntax_highlighting <https://wikipedia.org/wiki/Syntax_highlighting>`_

What it does
------------

Adds syntax highlighting to a range of source code languages. Note that this will not indent the
code. Use one of the 'Beautify' operations for that.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See

   scope and known boundaries.
