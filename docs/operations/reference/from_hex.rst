From Hex
========

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``byteArray``

**Background:** `https://wikipedia.org/wiki/Hexadecimal <https://wikipedia.org/wiki/Hexadecimal>`_

What it does
------------

Converts a hexadecimal byte string back into its raw value. e.g. ``ce 93 ce b5 ce b9 ce ac 20 cf 83
ce bf cf 85 0a`` becomes the UTF-8 encoded string ``Γειά σου``

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
