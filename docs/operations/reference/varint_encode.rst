VarInt Encode
=============

**Category:** Serialisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``byteArray``

**Background:** `https://developers.google.com/protocol-buffers/docs/encoding#varints <https://developers.google.com/protocol-buffers/docs/encoding#varints>`_

What it does
------------

Encodes a Vn integer as a VarInt. VarInt is an efficient way of encoding variable length integers
and is commonly used with Protobuf.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See

   scope and known boundaries.
