Generate PGP Key Pair
=====================

**Category:** PGP

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Pretty_Good_Privacy <https://wikipedia.org/wiki/Pretty_Good_Privacy>`_

What it does
------------

Generates a new public/private PGP key pair. Supports RSA and Eliptic Curve (EC) keys.
