Regular expression
==================

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

**Background:** `https://wikipedia.org/wiki/Regular_expression <https://wikipedia.org/wiki/Regular_expression>`_

What it does
------------

Define your own regular expression (regex) to search the input data with, optionally choosing from a
list of pre-defined patterns. Supports extended regex syntax including the 'dot matches all' flag,
named capture groups, full unicode coverage (including ``\p{}`` categories and scripts as well as
astral codes) and recursive matching.

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
