Parse IPv6 address
==================

**Category:** Networking

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/IPv6_address <https://wikipedia.org/wiki/IPv6_address>`_

What it does
------------

Displays the longhand and shorthand versions of a valid IPv6 address. Recognises all reserved ranges
and parses encapsulated or tunnelled addresses including Teredo and 6to4.

   Status here means the operation name is implemented and callable. It does not by
