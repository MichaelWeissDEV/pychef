From Case Insensitive Regex
===========================

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Regular_expression <https://wikipedia.org/wiki/Regular_expression>`_

What it does
------------

Converts a case-insensitive regex string to a case sensitive regex string (no guarantee on it being
the proper original casing) in case the i flag wasn't available at the time but now is, or you need
it to be case-sensitive again. e.g. ``[mM][oO][zZ][iI][lL][lL][aA]/[0-9].[0-9] .*`` becomes
``Mozilla/[0-9].[0-9] .*``
