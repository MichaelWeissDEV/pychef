LS47 Decrypt
============

**Category:** Ciphers

**Input / output:** ``string`` → ``string``

**Background:** `https://github.com/exaexa/ls47 <https://github.com/exaexa/ls47>`_

What it does
------------

This is a slight improvement of the ElsieFour cipher as described by Alan Kaminsky. We use 7x7
characters instead of original (barely fitting) 6x6, to be able to encrypt some structured
information. We also describe a simple key-expansion algorithm, because remembering passwords is
popular. Similar security considerations as with ElsieFour hold. The LS47 alphabet consists of
following characters: ``_abcdefghijklmnopqrstuvwxyz.0123456789,-+*/:?!'()`` An LS47 key is a
permutation of the alphabet that is then represented in a 7x7 grid used for the encryption or
decryption.
