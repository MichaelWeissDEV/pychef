Unescape Unicode Characters
===========================

**Category:** Text

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

What it does
------------

Converts unicode-escaped character notation back into raw characters. Supports the prefixes:

- ``\u``

- ``%u``

- ``U+``

e.g. ``\u03c3\u03bf\u03c5`` becomes ``σου``
