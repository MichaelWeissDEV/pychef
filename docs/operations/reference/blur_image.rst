Blur Image
==========

**Category:** Image

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``ArrayBuffer``

**Background:** `https://wikipedia.org/wiki/Gaussian_blur <https://wikipedia.org/wiki/Gaussian_blur>`_

What it does
------------

Applies a blur effect to the image. Gaussian blur is much slower than fast blur, but produces better
results.
