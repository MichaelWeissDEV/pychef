Argon2 compare
==============

**Category:** Crypto

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

What it does
------------

Tests whether the input matches the given Argon2 hash. To test multiple possible passwords, use the
'Fork' operation.
