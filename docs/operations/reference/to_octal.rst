To Octal
========

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``byteArray`` → ``string``

**Background:** `https://wikipedia.org/wiki/Octal <https://wikipedia.org/wiki/Octal>`_

What it does
------------

Converts the input string to octal bytes separated by the specified delimiter. e.g. The UTF-8
encoded string ``Γειά σου`` becomes ``316 223 316 265 316 271 316 254 40 317 203 316 277 317 205``

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
