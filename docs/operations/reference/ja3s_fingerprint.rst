JA3S Fingerprint
================

**Category:** Crypto

**Input / output:** ``string`` → ``string``

**Background:** `https://engineering.salesforce.com/tls-fingerprinting-with-ja3-and-ja3s-247362855967 <https://engineering.salesforce.com/tls-fingerprinting-with-ja3-and-ja3s-247362855967>`_

What it does
------------

Generates a JA3S fingerprint to help identify TLS servers based on hashing together values from the
Server Hello. Input: A hex stream of the TLS Server Hello record application layer.

   Status here means the operation name is implemented and callable. It does not by
