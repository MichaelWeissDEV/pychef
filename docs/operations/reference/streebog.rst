What it does
------------

Streebog is a cryptographic hash function defined in the Russian national standard GOST R 34.11-2012
Information Technology – Cryptographic Information Security – Hash Function. It was created to
replace an obsolete GOST hash function defined in the old standard GOST R 34.11-94, and as an
asymmetric reply to SHA-3 competition by the US National Institute of Standards and Technology.
