What it does
------------

Takes a 'Defanged' Universal Resource Locator (URL) and 'Fangs' it. Meaning, it removes the
alterations (defanged) that render it useless so that it can be used again.

.. note::

   Status here means the operation name is implemented and callable. It does not by

   scope and known boundaries.
