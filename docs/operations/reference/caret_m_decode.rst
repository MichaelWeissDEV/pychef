Caret/M-decode
==============

**Category:** Encoding

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``byteArray``

**Background:** `https://en.wikipedia.org/wiki/Caret_notation <https://en.wikipedia.org/wiki/Caret_notation>`_

What it does
------------

Decodes caret or M-encoded strings, i.e. ^M turns into a newline, M-^] turns into 0x9d. Sources such
as `cat -v`. Please be aware that when using `cat -v` ^_ (caret-underscore) will not be encoded, but
represents a valid encoding (namely that of 0x1f).
