Hex Density chart
=================

**Category:** Visualisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

What it does
------------

Hex density charts are used in a similar way to scatter charts, however rather than rendering tens
of thousands of points, it groups the points into a few hundred hexagons to show the distribution.
