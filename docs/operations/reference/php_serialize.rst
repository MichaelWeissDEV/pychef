PHP Serialize
=============

**Category:** Serialisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``JSON`` → ``string``

**Background:** `https://www.phpinternalsbook.com/php5/classes_objects/serialization.html <https://www.phpinternalsbook.com/php5/classes_objects/serialization.html>`_

What it does
------------

Performs PHP serialization on JSON data. This function does not support ``object`` tags. Since PHP
doesn't distinguish dicts and arrays, this operation is not always symmetric to ``PHP Deserialize``.
Example: ``[5,"abc",true]`` becomes ``a:3:{i:0;i:5;i:1;s:3:"abc";i:2;b:1;}``
