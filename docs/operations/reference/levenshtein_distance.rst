Levenshtein Distance
====================

**Category:** Arithmetic

What it does
------------

Levenshtein Distance (also known as Edit Distance) is a string metric to measure a difference
between two strings that counts operations (insertions, deletions, and substitutions) on single
character that are required to change one string to another.
