To Hex Content
==============

**Category:** Encoding

What it does
------------

Converts special characters in a string to hexadecimal. This format is used by SNORT for
representing hex within ASCII text. e.g. ``foo=bar`` becomes ``foo|3d|bar``.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
   :doc:`../../compatibility` for the verified
   scope and known boundaries.
