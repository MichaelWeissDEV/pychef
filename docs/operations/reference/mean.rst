Mean
========

**Category:** Arithmetic

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``BigNumber``

**Background:** `https://wikipedia.org/wiki/Arithmetic_mean <https://wikipedia.org/wiki/Arithmetic_mean>`_

What it does
------------

Computes the mean (average) of a number list. If an item in the string is not a number it is
excluded from the list. e.g. ``0x0a 8 .5 .5`` becomes ``4.75``
