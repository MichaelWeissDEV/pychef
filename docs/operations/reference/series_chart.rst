Series chart
============

**Category:** Visualisation

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``html``

What it does
------------

A time series graph is a line graph of repeated measurements taken over regular time intervals.
