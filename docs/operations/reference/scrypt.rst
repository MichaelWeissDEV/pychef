What it does
------------

scrypt is a password-based key derivation function (PBKDF) created by Colin Percival. The algorithm
was specifically designed to make it costly to perform large-scale custom hardware attacks by
requiring large amounts of memory. In 2016, the scrypt algorithm was published by IETF as RFC 7914.
Enter the password in the input to generate its hash.
