Tar
========

**Category:** Compression

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``ArrayBuffer`` → ``File``

**Background:** `https://wikipedia.org/wiki/Tar_(computing) <https://wikipedia.org/wiki/Tar_(computing)>`_

What it does
------------

Packs the input into a tarball. No support for multiple files at this time.

.. note::

   Status here means the operation name is implemented and callable. It does not by
   itself promise byte-for-byte parity for every upstream option. See
