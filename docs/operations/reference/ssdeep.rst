What it does
------------

SSDEEP is a program for computing context triggered piecewise hashes (CTPH). Also called fuzzy
hashes, CTPH can match inputs that have homologies. Such inputs have sequences of identical bytes in
the same order, although bytes in between these sequences may be different in both content and
length. SSDEEP hashes are now widely used for simple identification purposes (e.g. the 'Basic
Properties' section in VirusTotal). Although 'better' fuzzy hashes are available, SSDEEP is still
one of the primary choices because of its speed and being a de facto standard. This operation is
fundamentally the same as the CTPH operation, however their outputs differ in format.
