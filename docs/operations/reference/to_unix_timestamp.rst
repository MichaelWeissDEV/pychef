To UNIX Timestamp
=================

**Category:** Date / Time

**Status:** Registered and callable in the CyberChef 11.3.0 compatibility inventory.

**Input / output:** ``string`` → ``string``

**Background:** `https://wikipedia.org/wiki/Unix_time <https://wikipedia.org/wiki/Unix_time>`_

What it does
------------

Parses a datetime string in UTC and returns the corresponding UNIX timestamp. e.g. ``Mon 1 January
2001 11:00:00`` becomes ``978346800`` A UNIX timestamp is a 32-bit value representing the number of
seconds since January 1, 1970 UTC (the UNIX epoch).
