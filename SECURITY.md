# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for this repository:

<https://github.com/MichaelWeissDEV/pychef/security/advisories/new>

Include the affected version, a minimal reproduction, expected impact, and any
known mitigations. Reports will be acknowledged as soon as practical.

## Cryptographic scope

PyChef includes pure-Python cryptographic implementations for compatibility,
education, testing, and CTF workflows. They are not a substitute for an audited
cryptographic library when protecting production secrets.
